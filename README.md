I also build tooling for AI-assisted development: giving coding agents better context about a codebase and automating the repetitive parts of the workflow.

**Selected projects**

- [**CodeVisualizer**](https://github.com/manwoodgrove/CodeVisualizer): parses a JS/TS repository into a call and import graph and renders it in 3D with PlayCanvas, so you can watch a call chain travel through the code. TypeScript, Fastify, React.
- [**cable-planning-sim**](https://github.com/manwoodgrove/cable-planning-sim): a browser BIM tool for planning conduit and cable runs, authoring real IFC geometry that round-trips to Revit and other BIM tools.
- [**nodriver on Twisted**](https://github.com/manwoodgrove/nodriver_twisted/tree/twisted): a port of the nodriver browser automation library from asyncio to Twisted, so it runs inside Scrapy on Windows.
- [**Grafteori**](https://manwoodgrove.github.io/Grafteori/): an interactive graph theory study guide with draggable example graphs (in Swedish).
